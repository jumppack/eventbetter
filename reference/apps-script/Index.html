Add subscription

Creates numbered events so you can see how long you've been subscribed.

How many Frequency units between each event. 1 = every month, 3 = every 3 months (quarterly), 6 = every 6 months. With Weekly, 2 = every 2 weeks. How many events to add to your calendar. If you set an End date, it stops at whichever comes first.
The name each event gets. Words in { } are replaced automatically for every event.
  • {name} the Title above
  • {count} event number: 1, 2, 3
  • {ord} event number as a position: 1st, 2nd, 3rd
  • {elapsed} total units passed: count × Repeat every
  • {unit} month, week, year or day
  • {units} unit pluralised to match {elapsed}: 1 month, 2 months
Examples
  • {name}: {ord} {unit} over → Tuff Gym membership: 3rd month over
  • {name}: {elapsed} {units} done → Tuff Gym membership: 3 months done
  • {name}: {ord} renewal, {elapsed} {units} in (repeat every 3) → Tuff Gym membership: 2nd renewal, 6 months in
Adds one extra event on the start date itself, e.g. {name} started → Tuff Gym membership started. Leave blank to skip. The grey text is only a hint, not a value. Which Google Calendar the events go into. A name like "Subscriptions" creates a separate calendar (if it doesn't exist) that you can hide or delete in one click. Leave blank to use your main calendar.
